Sistema de gerenciamento de EPIs feito com Django como requisito parcial para a matéria de Desenvolvimento de Sistemas.
Nesta etapa: CRUD de colaboradores (cadastrar, listar, pesquisar por nome, editar e excluir).

## Como executar

1. Clone o repositório:
```
git clone https://github.com/SEU_USUARIO/NOME_DO_REPO.git
cd NOME_DO_REPO
```

2. Instale as dependências:
```
pip install -r requirements.txt
```

3. Crie o banco de dados:
```
python manage.py migrate
```

4. Inicie o servidor:
```
python manage.py runserver
```

5. Acesse no navegador: http://127.0.0.1:8000
